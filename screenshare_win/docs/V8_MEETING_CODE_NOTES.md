# V8 会议码加入说明

本版本在 v7 多人会议基础上增加了“会议码”流程，主要用于本机多开 Demo：

1. 主机端点击“创建会议”。
2. 程序随机生成一个 6 位会议码，并弹出小窗显示。
3. 其他窗口点击“加入会议”。
4. 在弹出的输入框中输入会议码。
5. 会议码正确才允许加入；会议码错误会提示“会议码错误，无法加入会议”。

当前默认仍使用本机地址 `127.0.0.1:9000`，所以适合本机三开/多开测试。若后续要跨电脑使用，需要再增加主机 IP 输入、局域网发现或中心注册服务。

## 摄像头提示优化

本机多开测试时，同一个物理摄像头通常只能被一个 exe 占用。若第二个窗口继续打开同一个摄像头，会显示中文提示：

> 摄像头打开失败：该设备可能已被其他程序占用，或当前没有权限访问摄像头。

建议使用多个摄像头或 OBS Virtual Camera 进行多人摄像头测试。
