# 手动验证清单

## 屏幕共享

- [ ] 单屏共享：选择主屏开始共享，预览窗口与远端画面持续更新。**通过判定：** 预览与远端均能稳定看到主屏内容，拖动窗口/滚动页面时肉眼延迟小于 200ms。
- [ ] 多屏共享第 2 屏：在双屏环境选择第 2 屏。**通过判定：** 捕获内容来自第 2 屏，工具条与预览仍可正常操作。
- [ ] 4K / 高 DPI 屏幕：在 4K 或缩放屏幕开始共享。**通过判定：** 预览与远端分辨率正常、比例正确，无明显卡顿或拉伸。

## 窗口共享

- [ ] 普通窗口（记事本）：选择记事本窗口共享。**通过判定：** 输入文字、滚动内容时预览同步跟随，无多秒级滞后。
- [ ] 浏览器窗口：选择浏览器窗口共享。**通过判定：** 切换标签、滚动页面、播放普通网页动画时预览持续更新。
- [ ] 最小化后恢复：共享窗口最小化，再恢复。**通过判定：** 最小化期间给出提示或暂停更新；恢复后自动继续采集。
- [ ] 移动窗口：拖动被共享窗口位置。**通过判定：** 预览与批注层持续跟随窗口位置，无错位。
- [ ] 关闭被共享窗口：直接关闭目标窗口。**通过判定：** 共享自动停止，并弹出明确提示，不崩溃。

## 画笔 / 批注

- [ ] 笔迹绘制：开启批注后连续画线。**通过判定：** 本地预览与远端画面都能看到笔迹叠加。
- [ ] 橡皮擦：对已有笔迹执行擦除。**通过判定：** 擦除结果立即反映到预览与远端。
- [ ] 文字工具：添加文字批注。**通过判定：** 文字位置、字号、颜色符合选择结果。
- [ ] 撤销 / 重做：连续绘制后执行撤销两次、重做一次。**通过判定：** 预览和远端状态与预期一致。
- [ ] 清空：执行清空操作。**通过判定：** 所有批注立即消失，后续可继续绘制新内容。
- [ ] 关闭后再次开启：关闭批注再重新开启。**通过判定：** 工具状态正确恢复，不出现残留悬浮输入框。
- [ ] 窗口共享跟随：在窗口共享模式下绘制批注并移动窗口。**通过判定：** 批注层持续贴合目标窗口，无漂移。

## 音频

- [ ] 仅麦克风：关闭系统声音，仅保留麦克风。**通过判定：** 远端能听到麦克风，本地预览 Mic 电平正常跳动。
- [ ] 仅系统声音：关闭麦克风，仅保留系统声音。**通过判定：** 播放系统音频时远端可听见，System 电平正常。
- [ ] 麦克风 + 系统声音：同时开启两路音频。**通过判定：** 两路音频均可发送，人声较大时系统音被压低（ducking 生效）。
- [ ] 本地回放警告：第一次开启本地回放。**通过判定：** 仅弹出一次警告，之后再次开启不重复弹窗。
- [ ] 静音切换：连续切换麦克风静音。**通过判定：** 静音后麦克风音频停止发送，取消静音后恢复。
- [ ] 本地回放开关：开启/关闭本地回放。**通过判定：** 开启后能听到混音，关闭后立即停止播放，无异常报错。

## 退出稳定性

- [ ] 共享中关闭主窗口。**通过判定：** 程序正常退出，控制台不出现 `terminated abnormally`。
- [ ] 先停止共享再退出。**通过判定：** 程序正常退出，无崩溃或卡死。
- [ ] 快速反复开关共享 10 次。**通过判定：** 每次都能正常开始/停止，共享结束后退出仍不崩溃。
